# ed-git-my_website- Green Bikes

Sitio web para la empresa ficticia Green Bikes, dedicada al alquiler de bicicletas urbanas y eléctricas.

## Tecnologías utilizadas
* HTML5
* CSS3

## Instrucciones de uso
Para visualizar la página web, clona este repositorio en tu equipo local y abre el archivo `index.html` en cualquier navegador web.
